# LOEBER // TERMINAL

Personal social media command center for Matt Loeber.

A Bloomberg-style terminal for tracking and optimizing content across TikTok, Instagram, YouTube, and X — built around ICT trading concepts (SMT, CISD, IFVG, Quarterly Theory) and the lifestyle brand it powers.

## Features

- **Overview**: Live account matrix and performance tickers driven by your weekly data
- **Sunday Review**: Structured intake form for weekly Metricool numbers
- **History**: Persistent archive of every week logged
- **Scripts**: 8 viral-ready scripts for trading content
- **Schedule**: 7-day content grid across all platforms
- **Trends**: Heat-ranked trend radar for the trading niche
- **Trade PDFs**: Carousel templates and design standards
- **Mentor AI**: Tier-ranked strategic directives + 30-day playbook

Data persists across sessions via browser localStorage. Deployed on Vercel.

## Deployment

Auto-deploys from the `main` branch via Vercel. Push to update.
